Generate the structure of a school activity to help students learn.
The activity must contain a layout structure where texts, images, tables or any other element that can help students' learning are positioned. 
These elements must be arranged in such a way that they are consistent with the proposed question. For example: if the question asks the student to link images, the images must be separated in such a way that it is possible for the student to link them.
The structure of the activity must be specified using the HTML language, and the CSS language to position text, images, tables, or any element present in the activity.
If the activity contains images, add a description of the image in the “alt” attribute. This description must be consistent with the activity specification and provide all the information necessary for the student to be able to answer the activity.
Also add an explanation for the elements used in the activity, in a new “exp” attribute. This attribute must be specified within the HTML tags and will explain the purpose of that structure in the activity. 
When it is necessary to use CSS, add an explanation in the form of comments above the class. This CSS is used to organize the layout of the activity so that it is creative and fun for the student.
Generate a textual description of the activity. This description must be specified in JSON format and must contain the following attributes:

task: the objective of the question, what the student will learn by answering.
layout: a detailed description of how each html elements are organized in the layout of the question, explain where the elements are placed.
answer: what the student will have to do to correctly answer that activity, add the answer and all the infos needed to answer the question

Generate the JSON description, and then generate the HTML structure containing the layout.
Do not generate iteractive HTML, this activitie is intended to be resolved with a pen and paper.
Be careful that the size of the images does not exceed the size of the activity

To generate a new activity use the following parameters:



level: 2nd year of fundamental
subject: addition
theme: snacks
sheet width: 700px
layout: observe image, write answer



Where:

level: is the school year is that activity intended for.
subject: is the school subject that activity is designed for.
theme: is the topic that activity wants to work on.
sheet width: is the desired width of the activity sheet.
task: is what the student must do to answer the activity.

Stick to the following rules:

Don't add anything outside the textual description and the HMTL of the activity.
Generate an activity that is creative and helps the student learn in a playful way, using the parameters specified above.


```json
{
  "task": "The student will learn to count and perform basic addition by identifying the number of sandwiches and juice boxes in the image and calculating the total.",
  "layout": "The activity is organized with an initial description at the top that sets the context. Below this, a centered image provides a visual reference. Following the image, there are three paragraphs containing questions related to it.",
  "answer": "To correctly answer this activity, the student needs to: 1) observe the image and count the number of sandwiches (4), 2) count the number of juice boxes (3), 3) perform the addition of both (4 + 3 = 7), and 4) write the answers in the corresponding boxes: A) 4 sandwiches, B) 3 juice boxes, C) total sum of 7."
}
```

```html
<!DOCTYPE html>
<html lang="en">
  <head></head>
  <body>
    <div
      style="width: 700px; border: solid 1px; padding: 10px; text-align: center;"
      exp="This div acts as the main container for the activity. It sets a fixed width of 700px with padding for spacing inside and centers the content."
    >
      <div class="activity" style="width: 100%;">
        <p
          exp="This paragraph provides a clear description of the task. The student needs to analyze the image and answer the questions below."
        >
          Observe the image below and answer the following questions:
        </p>

        <div
          style="display: flex; justify-content: center; margin-bottom: 20px;"
          exp="This div uses flexbox to horizontally center the image of the activity."
        >
          <img
            src=""
            alt="Image in a coloring book style containing 4 sandwiches and 3 juice boxes. In a table with 2 lines and 3 columns."
            style="width: 400px; height: auto;"
            exp="This image shows a coloring book style drawing of a table with 2 rows and 3 columns. In the first row, there are 4 sandwiches, and in the second row, there are 3 juice boxes. The purpose is to prompt students to count and add the quantities."
          />
        </div>

        <div style="display: flex; align-items: center; justify-content: flex-start; margin-bottom: 10px;">
          <p style="margin-right: 10px;">A) How many sandwiches are there?</p>
          <div
            style="width: 80px; height: 30px; border: 1px solid black;"
            exp="Box where the student writes the number of sandwiches (4)."
          ></div>
        </div>

        <div style="display: flex; align-items: center; justify-content: flex-start; margin-bottom: 10px;">
          <p style="margin-right: 10px;">B) How many juice boxes are there?</p>
          <div
            style="width: 80px; height: 30px; border: 1px solid black;"
            exp="Box where the student writes the number of juice boxes (3)."
          ></div>
        </div>

        <div style="display: flex; align-items: center; justify-content: flex-start;">
          <p style="margin-right: 10px;">C) What is the sum of sandwiches and juice boxes?</p>
          <div
            style="width: 80px; height: 30px; border: 1px solid black;"
            exp="Box where the student writes the total sum (7)."
          ></div>
        </div>
      </div>
    </div>
  </body>
</html>
```

```json
{
  "task": "The student will learn to count and perform basic addition by identifying the number of sandwiches and juice boxes in the images and calculating the total.",
  "layout": "The activity is organized with a description at the top, followed by a grid layout with three rows and two columns. In the first row, there is an image of sandwiches positioned next to an empty area. In the second row, an image of juice boxes is placed next to an empty area. The third row contains a plus sign next to an equal sign, with a box for the student to write the result.",
  "answer": "To correctly answer this activity, the student needs to observe the images and identify that there are 4 sandwiches and 3 juice boxes. ```html
```
```html
<!DOCTYPE html>
<html lang="en">
  <head></head>
  <style>
    /* class used to organize the sandwiches and juice boxes images in the activity layout  */
    .container {
      display: grid;
      grid-template-columns: 300px 300px;
      grid-template-rows: 300px 100px 300px;
      grid-template-areas:
        "sandwiches empty1"
        "juiceboxes empty2"
        "plus equal result";
    }

    /* class used to position the sandwiches image in the first cell of the first column */
    .sandwiches {
      grid-area: sandwiches;
    }

    /* class used to position the juice boxes image in the first cell of the second column */
    .juiceboxes {
      grid-area: juiceboxes;
    }

    /* class used to position the plus sign in the second cell of the first column */
    .plus {
      grid-area: plus;
      font-size: 50px;
      display: flex;
      justify-content: center;
    }

    /* class used to position the equal sign in the second cell of the second column */
    .equal {
      grid-area: equal;
      display: flex;
      justify-content: center;
    }

    /* class used to position a box that will be used for the student to write the result of the sum, the box is positioned in the middle of the first column of the third row */
    .result {
      grid-area: result;
      border: solid 1px;
    }

    /* class used to adjust the size of the images in the activity */
    img {
      width: 280px;
      height: 280px;
    }
  </style>
  <body>
    <div
      style="width: 700px; border: solid 1px"
      exp="div containing the sheet width, which in this case is 700px"
    >
      <div class="activity" style="width: 700px">
        <p
          exp="Activity description, containing the explanation of what the student will have to do to answer the activity correctly"
        >
          Observe the images below and write the sum of the quantity of sandwiches and juice boxes.
        </p>

        <div class="container">
          <div class="sandwiches">
            <img
              alt="Image in a painting style containing 4 sandwiches"
              exp="Image that the student will have to identify that there are 4 sandwiches"
            />
          </div>

          <div class="juiceboxes">
            <img
              alt="Image in a painting style containing 3 juice boxes"
              exp="Image that the student will have to identify that there are 3 juice boxes"
            />
          </div>

          <div class="plus">
            <p
              exp="Sign that represents the sum of the quantities of sandwiches and juice boxes"
            >
              +
            </p>
          </div>

          <div class="equal">
            <p
              exp="Sign that represents the result of the sum of the quantities of sandwiches and juice boxes"
            >
              =
            </p>
          </div>

          <div class="result">
            <p
              exp="Box that will serve for the student to write the sum of sandwiches and juice boxes"
              style="display: flex; justify-content: center; align-items: center; width: 100px; height: 100px;"
            ></p>
          </div>
        </div>
      </div>
    </div>
  </body>
</html>
```
